# Examples of how to use the Azure SDK for .NET with Locally

This directory contains examples of how to use [the Azure SDK for .NET](https://github.com/Azure/azure-sdk-for-net) with [Locally](https://locally.build).

## Getting Started

The examples within this directory require both .NET and Locally to be installed.

Find out more about [Locally](https://locally.build) and how to get started in [our guide on using the Azure SDK for .NET with Locally](https://locally.build/docs/guides/using-locally-with-the-azure-sdk-for-dotnet).

## Note

At this time the Azure SDK for .NET must be manually configured to work with Locally, but we're looking to add support for [Automatic Configuration](https://localhost:2100/documentation/features/automatic-configuration) in the future.
